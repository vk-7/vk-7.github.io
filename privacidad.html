Política de privacidad de task

Última actualización: 3 de noviembre de 2026.

Qué datos usa

Con la autorización de la cuenta Google, task accede a Google Tasks (listas y tareas: título, notas, fechas y estado) mediante el permiso https://www.googleapis.com/auth/tasks. No accede a ningún otro dato de la cuenta.

Dónde se procesan

task se ejecuta solo en el equipo de su dueño. El token de acceso se guarda en ese equipo y no se envía a ningún servidor propio: no existe uno. El contenido de las tareas que el dueño consulta se entrega al asistente Claude Code que usa en ese mismo equipo, como parte de su conversación.

Con quién se comparten

Los datos no se venden, no se usan para publicidad y no se comparten con terceros. El uso de los datos recibidos de las API de Google cumple la Política de Datos del Usuario de los Servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El acceso se puede quitar en cualquier momento desde myaccount.google.com/permissions.
